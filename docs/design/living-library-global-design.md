# 活书房全局交互修正设计

> 状态：已实现，待人工美术复核。
> 基准：保留上一轮已经收敛的完整场景帧、空间构图、阅读层、设置面板和已审核交互素材。
> 范围：本轮只修正文字归属、搜索可用性、对象反馈时序、抬纸状态和黑屏闪烁，不重新设计活书房。

## 1. 设计边界

本轮问题需要从整体交互关系判断，但不意味着推翻上一轮设计。以下内容保持不变：

- 日景、夜景及已经人工确认的完整场景帧；
- 1800 x 1126 母版、原有相机、裁切和物件空间关系；
- 完整场景状态帧加透明命中区的运行方式；
- 当前阅读层的列表与详情布局；
- 当前设置面板及 Provider、飞书、数据管理结构；
- 已确认的书组级抽出表达，不追踪单本书籍一致性；
- 打字机、信件托盘、书架和台灯的现有产品入口。

本轮不做以下工作：

- 不拆建筑底板和独立物件图层；
- 不重新生成六套书组素材；
- 不把阅读层改成新页面或新的物理书本界面；
- 不把设置改成独立 Electron 窗口；
- 不重新排列记录详情和 AI Provider 设置；
- 不修改已经确认的日夜照明和场景构图。

## 2. 当前问题及最小修正

| 当前问题 | 原因 | 本轮修正 |
| --- | --- | --- |
| 非书架文字随意摆在桌上 | 原稿没有可承载这些文字的稳定位置 | 删除打字机、信件、台灯、搜索和设置的常驻文字 |
| 搜索记录无法实际输入 | 输入框被放在屏幕外，只保留了桌面文字热点 | 在窗口右上提供真实可见的搜索控件 |
| 搜索和设置像桌面陈设 | 工具能力与场景物件混在同一坐标系 | 两者改为窗口级图标工具，仍调用现有逻辑和面板 |
| 打字机关闭后出现悬空纸 | 抬纸状态与静止态不一致，窗口状态复位又增加叠加风险 | 完全取消抬纸图片和抬纸动画，打字机始终使用静止帧 |
| 书组抽出不可见 | 状态帧与已经完全展开的不透明阅读层在同一渲染时刻出现 | 一次点击同时提交已解码抽出帧和阅读层入场初态，让物件变化成为转场背景 |
| 信件抬起不可见 | 信件状态帧还未形成视觉反馈，阅读层已经处于最终覆盖状态 | 一次点击同时提交已解码抬起帧和阅读层入场初态，让物件变化成为转场背景 |
| 场景交互出现黑屏 | 大尺寸完整帧在未解码时直接替换当前 `<img src>` | 保留旧帧直到新帧加载并解码，再原位交换 |

## 3. 保留后的页面结构

活书房仍然只有当前一个主窗口，阅读层和设置面板继续在该窗口中打开：

```text
┌──────────────────────────────────────────────────────────────┐
│ 完整场景帧                                         搜索  设置 │
│                                                              │
│                书架分类文字位于原木横板                      │
│                                                              │
│     台灯                  打字机                 信件托盘     │
└──────────────────────────────────────────────────────────────┘
                         │
                         ├─ 单击书组/信件 -> 物件转场 -> 现有阅读层
                         ├─ 提交搜索          -> 现有阅读层
                         └─ 点击设置          -> 现有设置面板
```

窗口工具只解决搜索和设置的入口归属，不建立新的导航系统。

## 4. 文字布局

### 4.1 保留

只保留书籍分类相关常驻文字。分类名和数量继续位于当前木横板位置，并沿用当前母版坐标与对齐关系：

- `日记`、`思想`、`人物`、`阅读`、`目标`、`其他`；
- 数据加载完成后可以继续显示各分类数量；
- 不写入书脊，不增加文字底板或卡片；
- 选中态只调整现有文字明度，不改变位置和字号。

本轮不重新计算六个文字中心点。只有实际截图显示某一列偏移时，才针对该列做局部坐标修正。

### 4.2 删除

从场景中删除以下常驻文字：

- `写下记录` / `最近记录` / `读取中` / `重新读取`；
- `翻阅记录`；
- `切换日间` / `切换夜间`；
- `搜索记录`；
- `书房设置`。

打字机、信件和台灯仍是可点击真实物件。鼠标悬停或键盘聚焦时可以显示短工具提示，但工具提示不参与场景排版。

## 5. 搜索与设置

搜索和设置放在窗口右上角的 UI 安全区，不放在桌面图像坐标中：

- 两个图标按钮沿窗口右上角水平排列；
- 使用熟悉的搜索和设置图标，不显示常驻按钮文字；
- 默认状态保持克制，悬停和键盘聚焦时提供标准工具提示；
- 不添加卡片、说明面板或新的场景美术资源。

搜索交互：

1. 点击搜索图标后，在同一位置展开一个可见输入框。
2. 输入框立即获得焦点，继续使用当前 `queryInput` 和搜索提交逻辑。
3. `Enter` 提交后打开现有阅读层并显示搜索结果。
4. 搜索结果继续使用现有整行按钮，确保鼠标和键盘均可打开记录。
5. `Escape` 优先关闭搜索输入，不清除书组选择或关闭书房。

设置交互：

- 点击设置图标继续打开当前 `SettingsPanel`；
- 不改变设置面板内容、宽度、Provider 配置或数据管理流程；
- 只删除原来放在桌面上的设置文字和热点坐标。

## 6. 场景对象转场时序

### 6.1 书组

```text
单击分类 A
  -> 同时显示已解码的分类 A 抽出帧和阅读层入场初态
  -> 阅读层由画面外进入，遮罩从透明建立
  -> 阅读层到达现有最终位置并显示分类 A 筛选结果
```

- 全过程由一次点击触发，不产生等待用户再次确认的选择模式。
- 阅读层立即开始进入，没有人为停留或延迟；入场过程控制在 180-240 ms。
- 物件状态帧在阅读层背后保持到阅读层关闭，不在入场中途恢复 idle。
- 转场期间忽略同一入口的重复激活，避免打开多个阅读请求。
- 关闭阅读层后恢复 idle，沿用当前关闭行为，不新增导航历史。

### 6.2 信件托盘

```text
单击信件托盘
  -> 同时显示已解码的信件抬起帧和阅读层入场初态
  -> 阅读层由画面外进入，遮罩从透明建立
  -> 阅读层到达现有最终位置并显示最近记录
```

书组与信件使用同一转场控制器。场景同时只运行一个物件转场；新请求不能覆盖尚未解码的当前画面。

### 6.3 打字机

- 点击逻辑继续沿用当前产品行为，不在本轮重定义“新建/最近记录”规则。
- 点击前后场景图片都保持当前主题的 idle 或书组选择帧。
- 快速记录窗口显示、隐藏或销毁不再控制任何打字机图片状态。
- 不使用延时复位，不保留 `typewriter` 场景 action。

### 6.4 台灯

- 继续切换现有日景和夜景完整帧。
- 不增加新的灯具动画、粒子或 CSS 光效。
- 新主题帧解码完成前保留旧主题画面。

## 7. 完整帧无黑屏切换

保留完整帧方案，只修正加载顺序：

```text
请求状态帧
  -> 创建非显示 Image
  -> load
  -> decode()
  -> 下一 animation frame 更新 displayedSrc
  -> 当前可见图像替换完成
```

实现约束：

- `displayedSrc` 与业务请求状态分离；请求变化不能直接修改可见 `<img src>`。
- 加载或解码失败时继续显示旧帧，不显示黑底、空图片或错误图标。
- 初次 idle 显示后，空闲时预解码当前主题的书组和信件状态帧。
- 切换主题只预解码目标主题当前所需帧，不在首屏阻塞加载全部素材。
- 不使用黑色过渡层；本轮也不增加交叉淡化，以免改变已确认画面观感。
- `prefers-reduced-motion` 不影响资源解码与状态可见性。

如果完成完整帧预解码后仍出现窗口级黑屏，再单独检查 Electron 窗口 `show/hide` 和 GPU 合成；该排查不作为本轮场景重构理由。

## 8. 状态模型的最小调整

现有 `selectedType`、`sheetOpen`、`visualAction` 可以继续使用，并增加一个短生命周期的入场状态：

```ts
type SceneAction = "idle" | "letterbox";
type ReaderEntrance = "closed" | "entering" | "open";

async function activateShelf(type: MemoryType) {
  if (readerEntrance !== "closed") return;
  await ensureActionFrameDecoded(type);
  beginExistingReaderEntrance({ selectedType: type });
}

async function activateLetterbox() {
  if (readerEntrance !== "closed") return;
  await ensureActionFrameDecoded("letterbox");
  beginExistingReaderEntrance({ visualAction: "letterbox" });
}
```

- 从 `SceneAction` 删除 `typewriter`。
- `beginExistingReaderEntrance()` 在一次状态提交中设置场景动作帧、阅读数据和阅读层入场初态；下一 animation frame 进入最终位置。
- 只为现有阅读层增加位移和遮罩透明度入场，不改变其最终尺寸、布局或内容。
- 搜索展开状态新增在 `LibraryScene`，不引入新的全局路由。
- 阅读层和设置面板仍由现有 `sheetOpen`、`settingsOpen` 控制。

## 11. 验收边界

工程检查只确认：

- 搜索输入可见且结果可打开；
- 设置仍打开原设置面板；
- 单击书组/信件能够完成物件反馈并自动打开现有阅读层；
- 转场期间重复点击不会触发重复读取或多个阅读层；
- 打字机不再切换抬纸图片；
- 已解码图片替换过程中没有空帧；
- 现有阅读、设置和 Provider 功能没有回归。

静态截图只用于观察实际实现并输出美术指导，不产生自动美术通过结论；继续禁止录屏和桌面视频检测。
