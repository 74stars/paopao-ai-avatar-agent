# Paopao v0.1.0

Paopao v0.1.0 is the first desktop MVP baseline for local-first text capture and the Living Library.

## Included

- Always-available macOS and Windows text capture.
- Local SQLite source records, durable processing jobs and traceable derived content.
- Living Library browsing, search, revisions, category/summary correction, delete, export and backup restore.
- Named AI Provider profiles with write-only credentials protected by Electron safeStorage.
- Isolated simulated-data web Preview.

## Downloads

- Windows x64: `Paopao-Setup-0.1.0.exe`
- macOS Apple silicon: `Paopao-0.1.0-arm64.dmg`
- macOS Intel: `Paopao-0.1.0-x64.dmg`
- ZIP archives are provided for both macOS architectures.
- Verify every installer against `SHA256SUMS.txt`.

The tag workflow publishes this note only after all of the following pass:

- Full typecheck, tests, build, icon checks and Preview accessibility E2E.
- Native Windows and macOS Wave 4 E2E.
- Windows Authenticode verification for the installer and exact installed application.
- Developer ID signature, architecture and notarization-ticket verification for both macOS DMGs and both ZIP contents; each DMG is separately notarized and stapled.
- Clean-runner Windows NSIS install/SQLite-readiness/uninstall smoke and runner-native macOS DMG mount/SQLite-readiness/removal smoke.
- A deterministic SHA-256 manifest and GitHub provenance attestation covering every attached release asset.

`SIGNING-VERIFICATION-win.txt` and `SIGNING-VERIFICATION-mac.txt` are attached as release evidence.

## Data and uninstall behavior

Paopao stores user data locally. Windows uninstall and macOS application removal intentionally do not delete the user-data directory. Export or back up data from Settings before destructive maintenance.

## MVP boundaries

Voice, image, link and file capture, reports, cloud sync and the Feishu product connection are not part of this MVP release. The public web Preview uses isolated simulated data and does not connect to the desktop database.
