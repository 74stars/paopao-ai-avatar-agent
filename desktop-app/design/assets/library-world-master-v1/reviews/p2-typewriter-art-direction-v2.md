# P2 打字机基准候选美术指导 V2

> 人工审核结论：2026-08-12 通过。本结论只批准打字机静止态基准，不代表 P2 整体完成。

P1 日景底板保持已审核版本。

## 模型生产事实

- 使用 CRS 渠道 `gpt-image-2` 高质量图像编辑。
- 输入包括 P1 底板、原稿完整画面和原稿打字机局部。
- 最终链路先在 P1 中生成同场景打字机，再对模型结果作一次限定区域精修。
- 模型原始整图归一至 1800 x 1126 后，只将既有打字机蒙版内的像素回合到 P1；蒙版外继续使用已审核 P1。
- 本轮没有把 CSS、旧 `v4/v4.1` 剪片或原稿矩形背景抠图用于候选。

## 当前画面判断

候选已经恢复原稿的核心空间关系：打字机位于中央暗柜内，接触桌面并接受左侧暖光；机身、纸张、柜内暗部和桌面反射处于同一摄影环境，不再表现为悬浮商品图或带背景矩形的贴片。

相对原稿仍有可见差异：

- 候选机身前后厚度略大，整体体积比原稿更重。
- 候选右侧机构和暗部占比略大，原稿右缘更收敛。
- 纸张轮廓已经比上一候选缩小，但纸面仍比原稿略暖、略清晰。
- 键帽高光已经压低，仍比原稿更整齐、更具生成模型的规整感。
- 原稿中打字机周围存在台灯参与形成的环境光；当前只回填打字机，在台灯尚未生产前，局部明暗关系不能视为最终状态。

## 应保留部分

- 近正面的轻微俯视视点。
- 当前中心位置、机身整体宽度和落桌高度。
- 黑色机身为主、暗黄铜为辅的材质关系。
- 柜内环境遮蔽、桌面接触阴影和柔和反射。
- 蒙版外完全保留 P1 的生产方式。

## 下一轮美术动作

打字机基准已确认。下一检查点使用同一流程生产信件托盘；书组和台灯不并行展开，避免风格漂移。
