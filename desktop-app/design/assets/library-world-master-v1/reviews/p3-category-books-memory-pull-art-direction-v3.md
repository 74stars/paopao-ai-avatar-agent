# P3 第二组分类书组自然抽出状态美术指导 V3

状态：人工审核通过，但限定为`group-level-pull-abstraction`。上一轮 V2 因“未发现书脊抽出迹象”未通过，V2 候选已清除。本轮重新调用 CRS `gpt-image-2`，并直接查看模型原图、完整候选、局部和前后对照。

## 本轮只解决的问题

让三本相邻书脊形成可辨认的真实前移状态。候选将三本书放到比邻书更靠前的平面，略微增大投影，令底缘落到搁板前沿，并在两侧保留前排遮挡、后部连续暗槽和接触阴影。交互差异不再依赖单纯的色调或一条细缝。

## 当前画面观察

全景中，窗景、木作、台灯、桌面光池、打字机和信件托盘仍保持同一空间关系。上层中央书墙中左部可以看到一组三本较宽、较亮的前排书脊，其右侧和左侧与后排形成错层；书底仍与真实搁板接触，没有悬浮或转为正面封面。

局部对照用于人工判断前移是否足够明显、三本书是否被识别为一个整体、两侧邻书是否自然闭合，以及扩大后的状态区域是否仍保持原稿材质和透视。模型整图本身不作为最终场景，最终候选只将模型输出在限定区域内合成到批准 P2 最终日景。

人工审核确认：候选可用于抽象表达“书组被抽出”的交互状态，但候选中的每本书籍在静止态、相邻组和后续状态之间没有达到可追踪的一致性。因此本 checkpoint 批准的是书组整体的前移、前后层次、后部暗槽和接触阴影，不是单本书籍身份。

## 应保留的部分

- 三本书保持竖直、相邻、同一物理深度组。
- 前排底缘落在搁板前沿，后部暗槽连续且不变成矩形贴片。
- 原稿的暗部、木搁板、暖冷光、邻书和所有已批准物件。
- 场景仍是写实书房，不出现分类标签、按钮、文字或悬浮 UI。
- 素材只作为书组整体状态帧或整体交互参考使用，不拆出单本书脊作为跨状态复用资产。
- 不以单本书的纹理、宽度、高度、磨损或色调变化建立产品语义。

## 后续指导

可以继续使用该素材进行书组层级的交互抽出表达，但不得将每本书视为一致的独立资产。后续若需要单本书可追踪一致性，必须另行制作对象身份基准和对应状态帧；不得从本候选中推断。运行时接入仍需等待整体 P3 资产和交互语义验收，不由本 checkpoint 单独触发。
