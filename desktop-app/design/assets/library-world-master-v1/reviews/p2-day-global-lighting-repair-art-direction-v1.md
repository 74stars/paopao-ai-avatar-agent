# P2 日景全局照明返修美术指导 V1

状态：返修中。人工审核指出此前日景候选只有窗外略微发亮，室内木作、书墙、桌面和实体物件仍处于夜间低照度，因此此前 P2 日景通过记录及其依赖的 P3 日景状态暂不作为当前日景基准。

## 本轮只解决的问题

只修复全局日间环境光：让窗侧自然光进入并铺满书房，使木作、书墙、桌面、打字机、信件托盘、台灯和玻璃物件在室内都具有清晰的日间可见度。不能只提升窗外亮度，也不能用台灯暖光代替日光。

## 目标判断

不看窗外时，画面主体也应立即被识别为白天书房。书架背板、横梁、桌面和下层空间需要有可读的中间调与自然阴影；台灯仍是实体，但不应成为主要照明来源。全局曝光提升必须保留原稿的低饱和材质、木作纹理、玻璃反射和物件关系。

## 不变量

- 相机、裁切、透视、书架结构和窗景构图不变；
- 打字机、信件托盘、书墙、台灯、花瓶、玻璃穹顶和右侧横放书的位置、比例和数量不变；
- 只改变全局环境光、曝光、色温、阴影可见度和物件的日间材质响应；
- 不添加 UI、标签、按钮、卡片、发光描边或程序拼贴。
