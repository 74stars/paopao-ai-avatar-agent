# P2 信件托盘基准候选美术指导 V3

> 人工审核结论：2026-08-12 通过。本结论只批准信件托盘静止态基准，不代表 P2 整体完成。

P1 日景底板和打字机静止态基准保持已审核版本。

## 模型生产事实

- 使用 CRS 渠道 `gpt-image-2` 高质量图像编辑，共进行三轮同场景生成与定向精修。
- 输入包括已批准累积画面、原稿完整画面和原稿信件托盘局部。
- 模型原始整图会改写上层书组、台灯和全局木纹，因此未直接采用。
- 最终模型输出归一至 1800 x 1126 后，只将信件托盘既有蒙版内的像素回合到已批准累积画面；蒙版外继续使用 P1 与已批准打字机。
- 本轮没有使用 CSS、旧 `v4/v4.1` 剪片、邮件图标或原稿矩形背景抠图。

## 当前画面判断

候选保持了原稿的主要产品语义和空间关系：它是一只真实放置在右侧格架中的旧黄铜信件槽，不是卡片或悬浮邮件按钮；顶层信封、折线和暗红蜡封能够自然承担“浏览记录”的物件含义。托盘前壁、左圆角、后沿、右侧书脊、柜内暗部和搁板接触关系处于同一摄影空间。

相对原稿仍有可见差异：

- 候选信封纸面略亮、略偏黄，原稿更灰、更压入暗部。
- 候选托盘前壁右半部更平整，原稿有更明显的旧金属明暗起伏。
- 候选后沿略厚，右后角暗部比原稿更完整，生成感主要集中在这里。
- 候选蜡封位置和尺寸接近原稿，但表面高光更圆、更规整。
- 台灯尚未回填，左侧环境光与原稿完整画面不同；本轮只判断右侧物件自身和它与打字机的共同曝光。

## 应保留部分

- 当前在右侧格架中的位置、搁板高度和整体尺度。
- 低矮黄铜槽、宽幅顶层信封与单枚暗红蜡封的物件组合。
- 当前前壁高度、左圆角、收回后的右壁和宽信封轮廓。
- 低饱和旧黄铜、哑光纸张、深红蜡封与柜内暗部。
- 右侧书脊、接触阴影、搁板反射以及蒙版外累积画面。

## 下一轮美术动作

信件托盘基准已确认。下一检查点进入上层分类书组；台灯继续后置，因为其玻璃、火焰和桌面光池需要单独处理复杂光学关系。
